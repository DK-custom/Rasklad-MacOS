# Rasklad — состояние

Menu bar утилита для macOS, замена Punto Switcher. Swift, без зависимостей и Xcode.

## Готово (MVP п.1–4, проверено вживую 2026-10-21)
- Автопереключение: CGEventTap (listen-only) копит клавиши слова, на пробеле NSSpellChecker ru/en; Tab/Enter не триггерят.
- Правый ⌥: отмена автозамены (+ слово в исключения) → иначе перенабор текущего слова → иначе конвертация выделенного (⌘C/⌘V, буфер восстанавливается).
- Исключения слов: `~/Library/Application Support/Rasklad/exceptions.txt`; приложения и раскладка по приложениям — UserDefaults `local.rasklad`.

- Caps Lock (проверено вживую): хранится на каждое нажатие отдельно (`encodeKey`), применяется как ⇧ только к буквам каждой раскладки; заглавные слова проверяются строчными (NSSpellChecker считает CAPS-слова аббревиатурами); `selectLayout` возвращает Caps Lock, который macOS сбрасывает при TISSelectInputSource.
- ⇧+клавиша исправления (проверено вживую): определение выделенного — HTML-статьи системных словарей (частный DictionaryServices через dlsym, `Dictionary.swift`) в WKWebView, стиль `apple_client-panel` как у «Найти», шрифт 12px, до 3 статей (точный заголовок первым) из первого словаря по порядку настроек «Словаря» (`DCSActiveDictionaries`; служба отдаёт активные в произвольном порядке), подпись словаря; `color-scheme: light dark` обязателен для тёмной темы. Нет API → плоский DCSCopyTextDefinition. Снимок: `Rasklad --define-snapshot слово out.png [--dark|--light]`.
- Опечатки (проверено вживую): если раскладка верна, слово ≥4 букв не в словаре и NSSpellChecker.correction отличается на ≤1 правку (≤2 от 7 букв, перестановка = 1) — заменяется; CAPS не трогаем; отмена правым ⌥ → в исключения; меню «Исправлять опечатки» (UserDefaults `typos`).
- Короткие слова (1–3 буквы): решаются по спискам `commonShort` в `Detector.swift`, не по NSSpellChecker (тот принимает z, шт, иге, tot). Тест прогоняет оба списка в обе стороны. Новое частое короткое слово — добавить в список.
- Подсказки (`Hint.swift`, не проверено вживую): после автозамены «typed → fixed», после отмены «↩ … в исключения», определение — всё у курсора (AX kAXBoundsForRangeParameterizedAttribute), иначе у мыши. Неактивирующая панель; определение висит до клавиши/клика. В логе — «подсказка: у курсора/у мыши в <bundle id>».

- Fn/🌐 (проверено вживую): одиночное нажатие → мгновенно RU↔EN через `selectLayout` (без системного окна и задержки). Работает только при системном «🌐 → Ничего не делать» (`AppleFnUsageType == 0`), иначе молчит и подсказывает в меню. `ModifierTap` в `Detector.swift` общий для правого ⌥ и Fn.
- Окно настройки (`Onboarding.swift`; вёрстка — снимками, установка из DMG — вживую): права по очереди (первое нажатие — системный запрос, дальше — раздел Настроек), затем по желанию: быстрая смена по Fn (включает `fnSwitch` и ведёт отключать штатное 🌐, ✓ при `AppleFnUsageType == 0`), Caps Lock без смены языка (✓ при `TISRomanSwitchState == 0` в глобальном домене), выбор клавиши исправления (`CorrectionKey`: правый/левый ⌥, правый/левый ⌘, ⌃ Control; по умолчанию правый ⌥). Системные настройки Rasklad не пишет — только открывает и проверяет. Показ: без флага `onboarded` или без прав; меню «Настройка…» (⌘,). Снимок: `Rasklad --onboarding-snapshot out.png [--fresh|--half|--ready] [--dark]`.
- Автозагрузка: SMAppService.mainApp (включается при первом запуске, флаг `loginItemOffered`), пункт меню «Запускать при входе». Статус enabled подтверждён 2026-10-21.

- Иконка: `Rasklad.icns` (белое «Aa» на сине-фиолетовом градиенте), генератор `Tools/icon.swift`.

- Словарь macOS «IT-термины» (`ItDict/`, собран и установлен в `~/Library/Dictionaries/ITTerms.dictionary`, поиск проверен через DictionaryServices; в «Словаре» включает пользователь; папка словарей в контейнере «Словаря» — ссылка на `~/Library/Dictionaries`, копия одна; версия словаря = дата + хэш, Rasklad при запуске обновляет установленный, если вложенный другой): FOLDOC (`ItDict/foldoc/Dictionary.txt`, GNU FDL, 11 936 статей + 3 283 вторых имени из статей-ссылок) + `ItDict/ru_terms.tsv` (122 термина, «термин|синоним — пояснение»). Сборка: `python3 -I ItDict/build.py --install` (нужен `~/Developer/DictionaryDevelopmentKit` — путь без пробелов, Makefile набора их не переносит). Тест: `python3 -I ItDict/test_build.py`.

- Запрет правки в коде (``` проверено вживую в Claude 2026-10-21; редакторы кода в браузере — нет; меню «Не править код»): IDE и терминалы выключены по умолчанию (`codeAppIDs`, `com.jetbrains.*`; пользователь может включить — `allowedApps`), редакторы кода в браузере по AXDOMClassList (Monaco/CodeMirror/Ace), внутри ``` и `…` по тексту перед курсором (AX, до 4000 символов) или по недавно набранному. В лог — причина пропуска при её смене, без слов.

- Словарь «IT-термины» вложен в Rasklad.app (Resources, кладёт `build.sh`); шаг окна настройки ставит его в `~/Library/Dictionaries` и открывает «Словарь», ✓ — когда включён в `DCSActiveDictionaries`. Отдельной копии в контейнере «Словаря» нет — там ссылка на `~/Library/Dictionaries`.

- Безопасность: при `IsSecureEventInputEnabled()` и в `secureAppIDs` (loginwindow, SecurityAgent, заставка) — ничего не запоминаем и не правим; работает только Fn (смена раскладки для пароля). Найдено по логу 2026-10-21: правка срабатывала на экране блокировки. Активное приложение — `inputApp()` (владелец фокуса через AX, кеш 0,3 с): NSWorkspace.frontmostApplication после разблокировки залипает на loginwindow.

- Аудит и исправления: `AUDIT.md` (1.1 — все средние и низкие, кроме нотаризации).

- Фразы (1.2): язык фразы (`TypingState.phraseLang`) решает слова, которые есть в обоих языках («руку»/here); первое такое слово исправляется вместе со следующим (`phraseFix`). Первая отмена только возвращает слово, вторая за сеанс — в исключения (`UndoMemory`). Добавлены короткие: bye, bug, log, app, web, i'm, i'd.

- Раскладка + опечатка (1.3): `layoutTypoFix` — от 5 букв, в текущей раскладке не слово и не опечатка, исправление в другой должно иметь статью в словарях macOS (`inDictionaries`: проверка орфографии принимает бессмыслицу вроде «пкфапфтф»). Прогон: 12/13 исправлено, 0/75 ложных на жаргоне и сленге. Исправленное слово в `typoFix` тоже обязано быть словом.
- «Запомнить правописание» хранит служба AppleSpell: новые слова — не в `~/Library/Spelling/LocalDictionary` (там старые), а у службы (вероятно `~/Library/Group Containers/group.com.apple.AppleSpell`, извне не читается). Проверять/удалять: `NSSpellChecker.hasLearnedWord` / `unlearnWord` или «Забыть правописание». Rasklad учитывает выученные слова.

- 1.4: раскладка каждого нажатия (`TypingState.langs`) → `mixedFix` для слов из двух раскладок («ска;b» → «скажи»); `caseFix` для случайного Caps Lock посреди слова («правописанИЕ» → «правописание», «пРИВЕТ» → «Привет»; macOS/iOS/mRNA — список), после исправления регистра Caps Lock выключается. NSSpellChecker безразличен к регистру частых слов («приВЕТ» — слово).

- 1.5–1.6: «Забыть выученное слово…» (только `hasLearnedWord`, словарные не трогает; списка выученных macOS не отдаёт). Меню по разделам: Правка / Выделенный текст (рабочие пункты с клавишей в названии) / Клавиши / Слова / служебное с версией. `Rasklad --menu-dump` — структура меню текстом.

## Файлы
- `Sources/Layouts.swift` — таблицы RU/EN из системных раскладок (UCKeyTranslate), конвертация.
- `Sources/Detector.swift` — правило замены, тап правого ⌥.
- `Sources/Settings.swift`, `Sources/KeyTap.swift`, `Sources/main.swift` (меню, права, приложения).
- `Tests/main.swift` — самопроверка: `./build.sh test`. Сборка+установка+запуск: `./build.sh` → `/Applications/Rasklad.app`.
- Перенос: `./build.sh dist` → установщик `build/Rasklad.dmg` (универсальный arm64+x86_64, macOS 13+, внутри `Установка.txt` из `INSTALL.txt`). Gatekeeper отвергает (не нотаризовано) — на другом Mac один раз «Всё равно открыть». Установка из DMG проверена на этом Mac 2026-10-21 (с карантинной меткой): Gatekeeper → «Всё равно открыть» → окно настройки → права; после «Мониторинга ввода» macOS перезапускает приложение.

## Важное
- Подпись сертификатом «Rasklad Dev» (login keychain) — права TCC переживают пересборку. Без него ad-hoc и права слетают.
- Лог `~/Library/Logs/Rasklad.log`; слова пишутся только при `defaults write local.rasklad debug -bool true`.
- Mac «Russian»: запятая ⇧6, точка ⇧7, ё — `\`.

- Подпись проверена: после пересборки права сохранились (2026-10-21).

## Ограничения
- Отмена только сразу после замены; определение только для выделенного текста.

## Идеи на потом (обсуждено, отложено 2026-10-21)
- IT-термины в переключении/опечатках: build.py выгружает список терминов, Rasklad считает их словами (только точные формы).
- Имена файлов/почта/URL: переключать, если в другой раскладке «имя.расширение» с известным расширением.
- Проверка правописания выделенного по клавише: окно со списком ошибок и вариантами (NSSpellChecker; грамматика для ru слабая).
- iOS: системный словарь нельзя; варианты — веб-страница + быстрая команда или своё приложение с расширением «Поделиться».
