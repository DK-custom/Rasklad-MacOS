# Rasklad

[English](README.md) · **Русский**

Утилита для строки меню macOS вместо Punto Switcher: исправляет текст, набранный в неверной
раскладке (RU ↔ EN), мелкие опечатки и случайный Caps Lock, мгновенно переключает раскладку
по Fn/🌐 и показывает определения слов из словарей macOS. Swift, без сторонних зависимостей.

## Возможности

- **Автопереключение по пробелу:** `ghbdtn` → «привет», `рщц` → «how»; короткие слова — по спискам
  частых слов; слова, которые есть в обоих языках («руку» / here), — по языку фразы.
- **Опечатки:** `првиет` → «привет», в том числе вместе с неверной раскладкой (`ghbtdn` → «привет»).
- **Слово из двух раскладок** (`ска;b` → «скажи») и **случайный Caps Lock** (`правописанИЕ` → «правописание»).
- **Клавиша исправления** (по умолчанию правый ⌥; можно левый ⌥, правый/левый ⌘, ⌃):
  отмена замены, перенабор текущего слова, только что набранного (сразу после пробела) или выделенного; с ⇧ — определение слова во всплывашке
  в стиле системной «Найти».
- **Fn/🌐** — смена раскладки без задержки macOS (штатное действие 🌐 отключается в Настройках).
- **Не трогает код:** IDE и терминалы, редакторы кода в браузере, текст внутри ``` и `…`.
- **Не трогает пароли:** поля паролей, экран блокировки, системные окна паролей.
- Исключения слов и приложений, раскладка по приложениям, подсказки у курсора, окно первого запуска.
- Словарь **«IT-термины»** для «Словаря» macOS: FOLDOC (~15 тыс. английских терминов) + русские IT-термины.

Слова никуда не отправляются; в журнал (`~/Library/Logs/Rasklad.log`) набранный текст не пишется.

## Требования

- macOS 13+ (Apple Silicon и Intel), раскладки «ABC» и «Русская».
- Для сборки — Command Line Tools (`xcode-select --install`), Xcode не нужен.
- Для словаря «IT-термины» — Dictionary Development Kit из «Additional Tools for Xcode»
  (developer.apple.com/download/all) в `~/Developer/DictionaryDevelopmentKit` (путь без пробелов).

## Сборка

```bash
./build.sh test   # самопроверка без фреймворков
./build.sh        # собрать, установить в /Applications и запустить
./build.sh dist   # установщик build/Rasklad.dmg для другого Mac
python3 -I ItDict/build.py --install   # пересобрать словарь «IT-термины» и установить
python3 -I ItDict/test_build.py        # тест сборщика словаря
```

Подпись: `build.sh` подписывает сертификатом «Rasklad Dev» из связки ключей, если он есть
(самоподписанный, только для подписи кода) — тогда права macOS сохраняются между пересборками;
иначе — ad-hoc, и права после каждой сборки придётся выдавать заново. Приложение не нотаризовано:
на другом Mac первый запуск — через «Конфиденциальность и безопасность» → «Всё равно открыть».

## Установка

Скачайте `Rasklad.dmg` в [выпусках](https://github.com/DK-custom/Rasklad-MacOS/releases/latest) (или соберите `./build.sh dist`), откройте и перетащите Rasklad в «Программы» — см. [INSTALL.txt](INSTALL.txt) (там же удаление).
Права «Универсальный доступ» и «Мониторинг ввода» выдаются в окне первого запуска.

## Устройство

| Файл | Что внутри |
|---|---|
| `Sources/main.swift` | меню, окно настройки, конвертация выделенного, определения, автозапуск |
| `Sources/KeyTap.swift` | перехват набора (CGEventTap), проверка слова по пробелу, перенабор |
| `Sources/Detector.swift` | правила: раскладка, короткие слова, фразы, опечатки, регистр, код, клавиши |
| `Sources/Layouts.swift` | таблицы символов из системных раскладок, переключение с сохранением Caps Lock |
| `Sources/Settings.swift` | настройки, исключения, приложения для кода, журнал |
| `Sources/Hint.swift` | подсказки у курсора, Accessibility-запросы к полю ввода |
| `Sources/Dictionary.swift` | статьи системных словарей, вложенный словарь «IT-термины» |
| `Sources/Onboarding.swift` | окно первого запуска |
| `Tests/main.swift` | самопроверка правил |
| `ItDict/` | сборка словаря «IT-термины» (FOLDOC + `ru_terms.tsv`) |
| `Tools/icon.swift` | генерация иконки |

Документы: [AUDIT.md](AUDIT.md) — аудит и исправления; `*_WINDOWS.md` — заметки для порта
подсказок, словарей и опечаток на Windows; [PROJECT_STATE.md](PROJECT_STATE.md) — состояние проекта.
