Rasklad — установка на другой Mac

Нужно: macOS 13 или новее, включённые раскладки «ABC» (или «U.S.») и «Русская».

1. Перетащите Rasklad.app в папку «Программы» (Applications).

2. Первый запуск. Приложение не заверено Apple, поэтому macOS его заблокирует:
   - откройте Rasklad.app двойным щелчком, в окне с предупреждением нажмите «Готово»;
   - Системные настройки → Конфиденциальность и безопасность → внизу «Rasklad заблокировано…» →
     «Всё равно открыть», подтвердите паролем.
   Это нужно один раз.

3. Права. При первом запуске откроется окно «Rasklad — настройка» — пройдите шаги по очереди:
   - «Универсальный доступ» → «Разрешить» → в системном окне «Открыть Системные настройки» → включить Rasklad;
   - «Мониторинг ввода» → так же;
   - галочки в окне появятся сами, перезапуск не нужен (после «Мониторинга ввода» macOS может
     предложить «Выйти и открыть снова» — согласитесь);
   - по желанию там же: «Быстрая смена языка по Fn/🌐» (кнопка «Включить» откроет Настройки клавиатуры —
     выберите «Нажатие клавиши 🌐» → «Действие не требуется»), «Caps Lock без смены языка»
     «Словарь IT-термины» (кнопка «Установить», затем «Словарь» → Настройки: включить его
     и поставить под «Толковый словарь русского языка») и «Клавиша исправления»
     (правый/левый ⌥, правый/левый ⌘ или ⌃ Control; по умолчанию правый ⌥);
   - «Готово». Окно в любой момент: меню «Аа» → «Настройка…».

4. Автозапуск при входе включается сам при первом запуске (пункт меню «Запускать при входе»).

5. Запасная смена языка на случай, если Rasklad не запущен: Клавиатура → Сочетания клавиш →
   Источники ввода → включить «Выбрать предыдущий источник ввода» (⌃Пробел).

Управление:
- автозамена слова в неверной раскладке и мелких опечаток — по пробелу; лишний пробел перед , . ! ? : ; ) »
  убирается сразу при наборе знака;
- клавиша исправления (по умолчанию правый ⌥) — отменить последнюю замену (при повторной отмене слово попадёт в исключения), иначе перенабрать
  текущее слово, сразу после пробела — предыдущее слово, иначе выделенный текст в другой раскладке;
- ⇧ + клавиша исправления — определение выделенного слова (в том числе из «IT-терминов»);
- в коде (IDE и терминалы, редакторы кода в браузере, внутри ``` и `…`) автоправки нет;
- Fn/🌐 — мгновенная смена RU ↔ EN;
- меню «Аа» — вкл/выкл функций, исключения слов, «Не править в …» для текущего приложения.

Язык интерфейса — как у macOS (русский или английский); можно выбрать отдельно для Rasklad:
Системные настройки → Основные → Язык и регион → Приложения.

Удаление:
1. Меню «Аа» → снять «Запускать при входе», затем «Выход».
2. Удалить Rasklad.app из «Программ».
3. Системные настройки → Конфиденциальность и безопасность → «Универсальный доступ» и «Мониторинг ввода»:
   выделить Rasklad и нажать «−».
4. По желанию — данные (в Finder: Переход → Переход к папке, ⇧⌘G):
   ~/Library/Dictionaries/ITTerms.dictionary          — словарь IT-термины (сначала выключите его в «Словаре»)
   ~/Library/Application Support/Rasklad              — исключения слов
   ~/Library/Logs/Rasklad.log                         — журнал (без набранных слов)
   ~/Library/Preferences/local.rasklad.plist          — настройки
