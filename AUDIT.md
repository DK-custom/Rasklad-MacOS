# Аудит Rasklad 1.0.2 и установщика — 2026-10-21

Метод: чтение всего кода (`Sources/*.swift`, `build.sh`, `ItDict/build.py`), проверка собранных
`/Applications/Rasklad.app`, `build/Rasklad.dmg`, `build/Rasklad.zip` (подпись, состав, Gatekeeper, лицензии).
«Проверено» — подтверждено командой; «вероятно» — следует из кода, вживую не воспроизведено.

## Средние

1. **Гонка при перенаборе слова (вероятно).** `KeyTap.retype` откладывает Backspace и набор на следующий
   проход главного цикла. Если пользователь успевает нажать следующую клавишу раньше, Backspace сотрёт её,
   а не конец исправляемого слова. Риск — у быстрой печати и автоповтора.
   Исправление: отправлять события прямо из обработчика перехвата, без `DispatchQueue.main.async`.
2. **Ручная конвертация без выделения в редакторах кода (вероятно).** Если слова в буфере нет и ничего
   не выделено, клавиша исправления делает ⌘C. VS Code и IDE JetBrains по ⌘C без выделения копируют
   всю строку → ⌘V вставит её перекодированную копию. Ручная клавиша работает и в исключённых приложениях.
   Исправление: проверять выделение через AX (`kAXSelectedTextAttribute`) до ⌘C; если пусто — ничего не делать.
3. **Буфер обмена восстанавливается по таймеру 0,3 с (вероятно).** В медленных приложениях (Electron)
   ⌘V может выполниться позже — вставится старое содержимое буфера, а скопированное пользователем в эти
   0,3 с пропадёт. Исправление: восстанавливать после смены `changeCount` / дольше; не трогать буфер,
   если пользователь сам скопировал что-то за это время.
4. **Запуск прямо из DMG или «Загрузок» (вероятно).** Автозагрузка (`SMAppService`) регистрирует текущий путь;
   из образа или из перемещённой системой копии (App Translocation) путь после отключения образа исчезнет.
   Исправление: при запуске не из `/Applications` / `~/Applications` — предупредить и предложить переместить.
5. **Обновления словаря не доходят до «Словаря» (проверено частично).** «Словарь» читает собственную копию
   в своём контейнере; шаг окна настройки обновляет только `~/Library/Dictionaries`, а при уже включённом
   словаре стоит ✓ — новые русские термины из новой версии Rasklad не появятся. Исправление: сравнивать
   версию вложенного и установленного словаря, показывать «Обновить» и просить переключить словарь в «Словаре».
6. **Запросы Accessibility в обработчике перехвата (вероятно).** `frontAppID()` — раз в 0,3 с на любом
   событии, `codeReason()` — на каждом пробеле (до ~20 запросов с таймаутом 0,1 с). В зависшем приложении
   ввод может подтормаживать, а macOS — отключить перехват по таймауту (он включается снова, в лог пишется).
   Исправление: проверку кода делать один раз на слово с общим лимитом времени.

## Низкие

7. «Автопереключение» в меню не сохраняется между запусками (остальные переключатели сохраняются).
8. Раскладки читаются один раз при запуске: после добавления/удаления источников ввода нужен перезапуск.
9. Набор Unicode идёт с кодом клавиши 0 (`A`): приложения, читающие код клавиши, а не символ
   (игры, удалённые рабочие столы), могут получить «a». Терминалы исключены по умолчанию.
10. Логика буфера слова, окна отмены и Caps Lock в `KeyTap` не покрыта автотестами (покрыты правила).
11. Лог `~/Library/Logs/Rasklad.log` без ротации (сейчас 6,7 КБ — не критично).
12. В `Установка.txt` нет раздела об удалении (автозагрузка, права, настройки, словарь, лог).
13. Сборка под macOS 13+ на SDK 26 — на macOS 13–15 не проверялась.

## Установщик и поставка

- Подпись: «Rasklad Dev», `codesign --verify --deep --strict` — цела в приложении и после распаковки ZIP (проверено).
- Gatekeeper отклоняет (`rejected`): самоподписанный сертификат, нет нотаризации, Hardened Runtime выключен,
  DMG не подписан — ожидаемо, обход «Всё равно открыть» описан. Без Apple Developer ID не устранить.
- Состав DMG: `Rasklad.app`, ярлык `Applications`, `Установка.txt`; ZIP — то же без ярлыка (проверено).
- Словарь FOLDOC (GNU FDL): авторство указано, полный текст лицензии входит в словарь статьёй
  «GNU Free Documentation License» (проверено) — требование лицензии выполнено.

## Без замечаний

- Поля паролей, экран блокировки, окна паролей — правка выключена всегда (исправлено в 1.0.1–1.0.2).
- В лог слова не пишутся (только при `debug`); данные никуда не отправляются.
- Свои синтетические события помечены и не попадают в разбор набора.
- Частный API словарей — через `dlsym` с откатом на публичный `DCSCopyTextDefinition`.
